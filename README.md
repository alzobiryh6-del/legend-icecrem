# معمل ايسكريم الاسطورة

تطبيق ويب عربي RTL يعمل على الهاتف والكمبيوتر، مناسب للنشر مباشرة على GitHub Pages.

## الوظائف
- الإنتاج اليومي بالتاريخ مع إمكانية تعديل السجل.
- الأصناف: منجو، جوافة، فراولة، اقلاص منوع، معسلات.
- التقرير الأسبوعي من الاثنين إلى الأحد.
- مسحوبات الموزعين: اسحاق القدسي، همام الزبيري.
- مسحوب المالك: امين القدسي.
- الشدة = 50 وحدة، وسعر الشدة للموزع = 1850 ر.ي.
- فاتورة مستقلة لكل موزع/جهة.
- مشاركة الفواتير والتقارير عبر زر المشاركة في الهاتف.
- عمولة الإنتاج = إجمالي إنتاج الأسبوع × 2.
- حفظ البيانات محلياً على الجهاز.
- يعمل كتطبيق PWA بعد فتحه من GitHub Pages وإضافته إلى الشاشة الرئيسية.
- تصميم الزبيري — 775154297.

## النشر على GitHub
1. أنشئ مستودعاً جديداً، مثلاً `legend-icecream`.
2. ارفع جميع الملفات والمجلدات كما هي.
3. اذهب إلى Settings > Pages.
4. في Build and deployment اختر GitHub Actions.
5. ادفع الملفات إلى فرع `main`.
6. سيظهر رابط التطبيق في Actions/Pages.

مهم: البيانات محفوظة محلياً في المتصفح، لذلك هذا الإصدار لا يزامن البيانات بين عدة أجهزة.


## رفع الملفات من الجوال
هذا الإصدار لا يحتوي على مجلدات. ارفع الملفات السبعة مباشرة إلى الصفحة الرئيسية للمستودع:
`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`.

بعد الرفع:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
